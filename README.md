# LifePass AI

**청년 1인가구 복지 절벽 방지·생애전환 시뮬레이터 MVP**

이 프로젝트는 단순히 현재 받을 수 있는 혜택을 추천하는 데서 멈추지 않고, 사용자의 소득·고용·주거 변화에 따라 **3개월·6개월·12개월 뒤 자격 변화**, **혜택 간 충돌**, **복지 절벽 위험**, **최적 신청 타임라인**을 계산하는 대회 제출용 MVP입니다.

> 주의: 이 저장소의 혜택명·기준값·월 환산효과는 **시연용 데모 데이터**입니다. 실제 서비스화 시 복지로, 정부24, 고용24, 지자체 공고, 법령 데이터, 기관별 API를 연결해 최신 조건으로 검증해야 합니다.

---

## 핵심 기능

1. **카카오톡 스타일 대화형 온보딩**
   - 자연어 문장에서 나이, 지역, 가구, 실업급여 잔여일, 현재/예상 소득, 월세, 의료비, 신용점수 등을 추출합니다.

2. **혜택 DB 20개 이상**
   - 청년월세, 주거급여, 국민취업지원제도, 청년내일저축, 청년도약계좌, 근로장려금, 의료비 지원, 정책금융 등 데모 혜택을 포함합니다.

3. **결정론적 자격 판정 룰엔진**
   - LLM이 자격을 임의로 판단하지 않도록 JSON 규칙을 Python 룰엔진으로 계산합니다.

4. **혜택 간 충돌·중복 제거**
   - 같은 주거지원 그룹, 고용지원 그룹, 정책금융 그룹 등 중복 수급 가능성이 있는 항목을 제외하고 최적 조합을 고릅니다.

5. **생애주기 전환점 예측**
   - 실업급여 종료, 예상 소득 발생, 근로 상태 변화에 따른 1·3·6·12개월 후 혜택 변화와 상실 위험을 계산합니다.

6. **복지 절벽 시뮬레이터**
   - 월소득 시나리오별로 유지/상실 혜택과 순효과를 비교하여 명목소득이 늘어도 실제 효과가 줄어드는 구간을 경고합니다.

7. **최적 신청 타임라인·체크리스트**
   - D-45 실업급여 종료 준비, 소득 발생 시점, 필요 서류, 전환 신청 순서를 제시합니다.

8. **근거 기반 설명용 로컬 RAG**
   - 외부 API 없이도 데모 지식베이스에서 관련 근거 문단을 검색해 설명합니다.

9. **기관/운영자 대시보드**
   - 샘플 사용자 집단의 고위험 복지 절벽 대상, 지역별 평균 지원효과, 상담 큐를 보여줍니다.

10. **자가 검증 스크립트**
    - 혜택 DB 무결성, 파서, 룰엔진, 충돌 최적화, 미래 전환, 복지 절벽, 관리자 지표, RAG, 리포트 생성을 자동 검증합니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

Streamlit 없이 핵심 리포트만 확인하려면:

```bash
python cli_demo.py
```

자가 검증:

```bash
python tests/verify_mvp.py
```

정상 출력 예시:

```text
PASS test_catalog
PASS test_parser
PASS test_rule_engine_and_conflicts
PASS test_future_transition
PASS test_timeline_and_cliff
PASS test_admin_metrics
PASS test_rag_and_report

ALL CHECKS PASSED
```

- **국민행복/공공데이터 AI**: 청년 1인가구 복지 절벽 방지 및 사각지대 조기 발굴

## MVP+ 안정화/개선 내역

이번 버전은 시연 중 오류를 막고, 공모전 영상에서 더 선명하게 보이도록 다음 기능을 추가했습니다.

### 1. 자연어 파싱 후 렌더링 오류 방지

기존 오류의 직접 원인은 Streamlit `number_input`에 들어간 현재 값이 위젯의 `max_value`보다 컸기 때문입니다. 예를 들어 자연어 파싱 결과 `rent=5,000,000`인데 UI가 `max_value=3,000,000`으로 고정되어 있으면 Streamlit이 `StreamlitValueAboveMaxError`를 발생시킵니다.

수정본은 `core/validation.py`의 `safe_widget_bounds()`와 `app.py`의 `safe_number_input()`을 통해 현재 값이 nominal max보다 커도 위젯의 최대값을 자동 확장합니다. 따라서 파싱값이 크거나 JSON 업로드값이 커도 앱이 죽지 않고 경고를 띄웁니다.

### 2. 입력값 검증/경고 레이어

`validate_profile()`을 추가해 자연어 파싱, 샘플 적용, JSON 업로드, 수동 입력값을 모두 검증합니다. 월세 300만원 초과, 월소득 2천만원 초과, 보증금 10억원 초과처럼 단위 오류 가능성이 있는 값은 앱을 중단하지 않고 사용자에게 확인 경고를 보여줍니다.

### 3. 자연어 금액 파서 개선

`월세 55`, `보증금 500`, `월상환 35`처럼 한국어 상담 문장에서 흔히 쓰는 단위 생략 표현을 만원 단위로 해석하도록 개선했습니다. 기존의 `월세 55`가 55원으로 들어갈 수 있는 약점을 보완했습니다.

### 4. 상담 우선도/인사이트 기능 추가

`core/insights.py`를 추가했습니다. 현재 소득 공백, 실업급여 잔여일, 주거비 부담, 신용점수, 1~3개월 내 혜택 상실 위험, 복지 절벽 경고를 조합해 설명 가능한 상담 우선도 점수와 즉시 권장 액션을 생성합니다.

### 5. 서류 체크리스트 자동 통합

최적 조합으로 선정된 혜택들의 필요 서류를 모아 중복 제거된 신청 서류 체크리스트를 생성합니다. 시연에서 “추천에서 끝나지 않고 실제 신청 준비까지 이어진다”는 점을 보여줄 수 있습니다.

### 6. JSON 업로드/분석 결과 패키지 다운로드

사이드바에서 프로필 JSON을 업로드할 수 있고, JSON 탭에서 프로필 및 분석 결과 패키지를 다운로드할 수 있습니다. 향후 REST API나 공공데이터 API 연동 시 request/response 계약으로 확장하기 좋습니다.

### 7. 녹색 계열 CSS 테마 적용

`app.py`에 밝은 녹색/민트/라임 계열 CSS를 추가해 대회 시연 영상에서 더 화사하게 보이도록 바꿨습니다. 히어로 카드, 인사이트 카드, 탭, 버튼, 메트릭 카드, 사이드바 스타일을 모두 개선했습니다.

### 8. 검증 테스트 추가

`tests/verify_mvp.py`에 검증/인사이트 테스트를 추가했습니다.

```bash
python tests/verify_mvp.py
```

정상 실행 시 다음 테스트까지 포함해 통과합니다.

```text
PASS test_validation_and_insights
ALL CHECKS PASSED
```
